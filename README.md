# naval-cardgame

Card game inspired by World of Warships's Pacific Front event.

## Features

- Build your own deck of ships and commanders through PvE campaigns
- More stats are used in combat than just a power level
- Active modifiers that can change how a ship performs in battle
- Weather
- Fleet Commanders
- Multiplayer PvP (With PvE for practice)

## How it works

### Units

Units are ships. A ship has a class, tier, and a set of stats. These stats are:

- Health
- Attack
- Defense
- Mobility
- Stealth
